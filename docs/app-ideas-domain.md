## App Ideas

- Feature: `src/features/app-ideas/`
- Routes: `/app/ideas`, `/app/ideas/new`, `/app/ideas/:ideaId`
- GraphQL: `appIdeas`, `appIdea`, `appIdeaAdd/Edit/Remove`
- Backend module: `xavi-platform-node` → `app-idea` (FTS español, status de ciclo de vida)
- Optimistic create/update/delete via TanStack Query (`appIdeaKeys`)
